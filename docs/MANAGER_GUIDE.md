# Manager User Guide - MedEnroll Pro

**For:** Managers and Credentialing Coordinators  
**Access Level:** Create and Update  
**Version:** 1.0

## Welcome, Manager!

As a **Manager**, you have the ability to create and update provider information in MedEnroll Pro. This guide explains what you can do and how to do it effectively.

---

## What You Can Do

### ✅ Your Permissions

**Provider Management:**
- ✅ View all providers and enrollments
- ✅ Create new providers
- ✅ Edit provider information (name, NPI, license, specialty)
- ✅ Update payer enrollments
- ✅ Add and edit practice locations
- ✅ Flag providers for recredentialing

**Reporting:**
- ✅ View all reports
- ✅ Export reports to CSV
- ✅ Generate payer enrollment reports

**Search & Filter:**
- ✅ Search providers by name, NPI, license
- ✅ Filter by status, specialty, priority
- ✅ Use advanced search features

### ❌ What You Cannot Do

- ❌ Delete providers (admin only)
- ❌ Manage user accounts (admin only)
- ❌ Change user roles (admin only)
- ❌ Access user management dashboard (admin only)
- ❌ Modify system settings (admin only)

## Your Daily Workflow

### Typical Manager Tasks

1. **Add New Providers**
   - Click "Add Provider" button
   - Enter provider details
   - Add practice locations
   - Set up payer enrollments

2. **Update Provider Information**
   - Search for provider
   - Click edit icon
   - Update fields as needed
   - Click Save

3. **Manage Payer Enrollments**
   - Open provider card
   - View/edit enrollment dates
   - Update enrollment status
   - Add notes for tracking

4. **Generate Reports**
   - Navigate to Reports page

   - Export to CSV for analysis
   - Share with stakeholders

5. **Flag for Recredentialing**
   - Identify providers needing renewal
   - Click flag icon
   - Monitor flagged providers in Priority View

## Step-by-Step Guides

### How to Add a New Provider

**Time Required:** 3-5 minutes

1. Click **"Add Provider"** button (blue, bottom left)
2. Fill in required fields:
   - Name (e.g., "John Smith")
   - Credential (e.g., "MD", "DO", "NP")
   - NPI (10-digit number)
   - License number
   - Specialty
3. Add practice location:
   - Location name
   - Address
   - Type (Primary/Secondary)
4. Set up payer enrollments:
   - Select payers
   - Enter enrollment dates
   - Add notes if needed
5. Click **"Save"** or **"Add Provider"**
6. ✅ Provider appears in dashboard

---

### How to Update Provider Information

**Time Required:** 1-2 minutes

1. **Find the provider:**
   - Use search box at top
   - Or scroll through provider list

2. **Enter edit mode:**
   - Click pencil/edit icon on provider card
   - Fields become editable

3. **Make changes:**
   - Update any field (name, license, specialty, etc.)
   - Modify payer enrollment dates
   - Add or edit notes

4. **Save changes:**
   - Click green "Save" button on card
   - Or press Enter
   - ✅ Changes saved immediately

---

### How to Export Reports

**Time Required:** 30 seconds

1. Click **"Reports"** in left sidebar
2. Choose report type:
   - Provider Summary Report
   - Payer Enrollment Report
   - Credentialing Status Report
3. Click **"Export to CSV"** button
4. File downloads to your computer
5. Open in Excel or Google Sheets

**Tip:** Payer Enrollment Report includes all notes!

---

### How to Use Priority View

**Purpose:** Focus on providers needing attention

1. Click **"Priority View: OFF"** button (top right)
2. Button turns red: **"Priority View: ON"**
3. View shows only flagged providers
4. Work through flagged items
5. Click again to return to all providers

**Use Cases:**
- Upcoming credential renewals
- Providers with expired licenses
- Enrollments needing updates

## Search and Filter Tips

### Effective Searching

**Search by:**
- Provider name (partial match works)
- NPI number (full or partial)
- License number
- Specialty

**Examples:**
- "Smith" → Finds all Smiths
- "1234" → Finds NPIs containing 1234
- "Primary Care" → Finds all primary care providers

### Using Filters

**Status Filter:**
- Active - Currently practicing
- Pending - Credentialing in progress
- Inactive - No longer active

**Specialty Filter:**
- Addiction Medicine
- Primary Care
- Behavioral Health
- Psychiatry
- (and more)

**Combine for Power:**
- Filter: "Active" + Search: "Behavioral Health"
- Result: All active behavioral health providers

## Understanding Your Role

### Manager vs. Viewer

**You have MORE access than Viewers:**
- Viewers can only read data
- You can create and edit data
- You can export reports
- You have full editing capabilities

**Key Difference:** Viewers are read-only, you can make changes

### Manager vs. Admin

**Admins have MORE access than you:**
- Admins can delete providers
- Admins can manage user accounts
- Admins can change user roles
- Admins have system configuration access

**Key Difference:** You cannot delete data or manage users

**When to Contact Admin:**
- Need to delete a provider
- Need to change someone's role
- Need help with user access
- System configuration issues

## Troubleshooting

### Issue: Cannot Save Changes

**Possible Causes:**
- Required field is empty
- Invalid data format
- Network connection issue

**Solutions:**
1. Check all required fields are filled
2. Verify NPI is 10 digits
3. Ensure dates are valid
4. Try saving again
5. Refresh page if needed

---

### Issue: Provider Not Appearing in Search

**Possible Causes:**
- Filters are active
- Search term doesn't match
- Provider status is filtered out

**Solutions:**
1. Clear all filters (set to "All")
2. Try different search terms
3. Check spelling
4. Scroll through full list

---

### Issue: Cannot Export Report

**Possible Causes:**
- Browser blocking download
- Temporary system issue

**Solutions:**
1. Check browser download settings
2. Allow pop-ups for this site
3. Try different browser
4. Contact admin if persistent
