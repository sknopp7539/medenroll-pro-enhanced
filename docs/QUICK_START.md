# MedEnroll Pro - Quick Start Guide

**Get started in 5 minutes!**  
**Version:** 1.0

---

## 1. Log In

1. Go to MedEnroll Pro URL
2. Click **"Sign In"** or **"Login"**
3. Choose your login method (Google, etc.)
4. Authorize access
5. ✅ You're in!

**First time?** Your account is created automatically on first login.

---

## 2. Understand Your Role

After logging in, check your role badge (if visible) or ask your admin.

### 🔴 Admin (Red Badge)
**You can do everything:**
- View, create, edit, delete providers
- Manage user accounts and roles
- Export reports
- Full system access

**Your menu:** Providers, Reports, Settings, **Users**

---

### 🔵 Manager (Blue Badge)
**You can create and edit:**
- View all providers
- Create new providers
- Edit provider information
- Export reports

**Your menu:** Providers, Reports, Settings

---

### ⚪ Viewer (Gray Badge)
**You can view only:**
- View all providers
- View reports
- Search and filter
- No editing allowed

**Your menu:** Providers, Reports, Settings

---

## 3. Navigate the Dashboard

### Left Sidebar Menu

**Providers** - Main dashboard with all providers  
**Reports** - View and export reports  
**Settings** - System configuration  
**Users** - Manage users (Admins only)

### Main Dashboard

**Top:** Statistics cards (totals, active, pending, inactive, flagged)  
**Middle:** Search and filter bar  
**Bottom:** Provider cards (scrollable)

---

## 4. Find a Provider

### Quick Search

1. Look for search box at top
2. Type provider name, NPI, or license
3. Results filter automatically
4. Click provider card to view details

**Example:** Type "Smith" to find all Smiths

### Use Filters

1. Click **"All Statuses"** dropdown
2. Select: Active, Pending, or Inactive
3. Click **"All Specialties"** dropdown
4. Select specialty
5. View updates automatically

---

## 5. View Provider Details

Each provider card shows:

- **Name and Credential** (top)
- **Status Badge** (Active/Pending/Inactive)
- **NPI** - 10-digit identifier
- **License** - Number and expiration
- **Specialty** - Provider's specialty
- **Next Credentialing** - Upcoming date
- **Practice Locations** - Where they work
- **Payer Enrollments** - Insurance enrollments

**Tip:** Click "+X more payers" to see all enrollments

---

## 6. Common Tasks by Role

### For Viewers 👀

**Check provider status:**
1. Search for provider
2. Look at status badge
3. Note: Green = Active

**Find NPI:**
1. Search provider name
2. Look for "NPI:" field
3. Copy number

**View reports:**
1. Click "Reports" in sidebar
2. Browse available reports
3. View on screen

---

### For Managers ✏️

**Add new provider:**
1. Click **"Add Provider"** (blue button, bottom left)
2. Fill in required fields
3. Add practice location
4. Set up payer enrollments
5. Click **"Save"**

**Edit provider:**
1. Find provider card
2. Click edit icon (pencil)
3. Update fields
4. Click green **"Save"** button

**Export report:**
1. Go to Reports page
2. Choose report type
3. Click **"Export to CSV"**
4. File downloads

---

### For Admins 👑

**Manage users:**
1. Click **"Users"** in sidebar
2. View all users
3. Search for specific user
4. Change role via dropdown
5. ✅ Role updated instantly

**Change user role:**
1. Open User Management
2. Find user in table
3. Click role dropdown (Actions column)
4. Select new role (Viewer/Manager/Admin)
5. Confirm success message

**Delete provider:**
1. Find provider card
2. Click delete icon (trash)
3. Confirm deletion
4. ⚠️ Action is permanent

---

## 7. Use Priority View

**What:** Shows only flagged providers (those needing attention)

**How:**
1. Look for **"Priority View: OFF"** button (top right)
2. Click to toggle ON
3. View shows only flagged providers
4. Click again to show all

**When:** Check providers needing recredentialing

---

## 8. Generate Reports

### For Managers and Admins

1. Click **"Reports"** in left sidebar
2. Choose report type:
   - Provider Summary
   - Payer Enrollment (includes notes!)
   - Credentialing Status
3. Click **"Export to CSV"**
4. Open in Excel/Google Sheets

### For Viewers

1. Click **"Reports"** in sidebar
2. View reports on screen
3. Use browser print (Ctrl/Cmd + P) if needed
4. Ask Manager to export if needed

## Common Questions

**Q: How do I know my role?**  
A: Check badge color or ask admin. Menu items also indicate role.

**Q: Can I change my own role?**  
A: No, only another admin can change your role.

**Q: Why can't I edit providers?**  
A: You're a Viewer. Ask admin to upgrade you to Manager.

**Q: How do I export reports?**  
A: Requires Manager or Admin role. Go to Reports → Export to CSV.

**Q: Where is the Users menu?**  
A: Only visible to Admins. If you don't see it, you're not an admin.

**Q: Can I delete providers?**  
A: Only Admins can delete. Managers can create/edit only.

**Q: How do I add a provider?**  
A: Managers/Admins: Click blue "Add Provider" button (bottom left).

**Q: What does the red flag mean?**  
A: Provider flagged for recredentialing (needs attention).

## Troubleshooting

### Can't log in
- Check internet connection
- Try different browser
- Clear browser cache
- Contact IT support

### Can't find provider
- Clear filters (set to "All")
- Try different search terms
- Check spelling
- Refresh page (F5)

### Can't save changes
- Check required fields
- Verify data format
- Refresh page
- Contact admin

### Page not loading
- Refresh (F5)
- Clear cache
- Try different browser
- Check internet connection
