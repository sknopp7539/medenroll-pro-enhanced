# Viewer User Guide - MedEnroll Pro

**For:** Viewers and Read-Only Users  
**Access Level:** View Only  
**Version:** 1.0

---

## Welcome, Viewer!

As a **Viewer**, you have read-only access to MedEnroll Pro. This means you can view all provider information, reports, and data, but you cannot make changes. This guide explains how to get the most out of your view-only access.

---

## What You Can Do

### ✅ Your Permissions

**Viewing Data:**
- ✅ View all providers and their information
- ✅ View payer enrollments and dates
- ✅ View practice locations
- ✅ See provider status (Active, Pending, Inactive)
- ✅ View credentialing dates
- ✅ See flagged providers

**Search & Navigation:**
- ✅ Search providers by name, NPI, license
- ✅ Filter by status and specialty
- ✅ Use Priority View to see flagged providers
- ✅ Navigate between pages

**Reports:**
- ✅ View all reports
- ✅ See report data on screen

### ❌ What You Cannot Do

- ❌ Create new providers
- ❌ Edit provider information
- ❌ Delete providers
- ❌ Export reports to CSV (Manager/Admin only)
- ❌ Change payer enrollments
- ❌ Flag/unflag providers
- ❌ Manage users or roles

## How to Find Information

### Using Search

**Search by:**
- Provider name (first or last)
- NPI number
- License number
- Specialty

**Tips:**
- Partial matches work (e.g., "Smith" finds all Smiths)
- Search is case-insensitive
- Clear search to see all providers again

**Examples:**
```
Search: "John" → Finds John Smith, Johnny Doe, etc.
Search: "1234" → Finds NPIs containing 1234
Search: "MD" → Finds all MDs (in name or credential)
```

---

### Using Filters

**Status Filter:**
- **All Statuses** - Show everyone (default)
- **Active** - Currently practicing providers
- **Pending** - Credentialing in progress
- **Inactive** - No longer active

**Specialty Filter:**
- **All Specialties** - Show everyone (default)
- **Addiction Medicine**
- **Primary Care**
- **Behavioral Health**
- **Psychiatry**
- (and more)

**Combining Search and Filters:**
1. Set status filter (e.g., "Active")
2. Set specialty filter (e.g., "Primary Care")
3. Type search term (e.g., "Smith")
4. Result: Active Primary Care providers named Smith

---

### Using Priority View

**What It Does:**
Shows only providers flagged for recredentialing (those needing attention)

**How to Use:**
1. Click **"Priority View: OFF"** button (top right)
2. Button turns red and shows **"Priority View: ON"**
3. View now shows only flagged providers
4. Click again to return to all providers

**When to Use:**
- Check which providers need attention
- Review upcoming renewals
- Monitor credentialing priorities

## Understanding Provider Information

### Provider Card Layout

**Top Section:**
- **Name** - Provider's full name
- **Credential** - MD, DO, NP, PA, etc.
- **Status Badge** - Green (Active), Yellow (Pending), or Gray (Inactive)
- **Flag Icon** - Red flag if needs recredentialing

**Left Column:**
- **NPI** - National Provider Identifier (10 digits)
- **License** - State license number and expiration
- **Specialty** - Provider's specialty area

**Right Column:**
- **Next Credentialing** - Upcoming credentialing date
- Shows days until due (e.g., "-487 days" = overdue)
- Color-coded: Red (overdue), Yellow (soon), Green (current)

**Practice Locations:**
- Primary and secondary locations
- Address information
- Location type

**Payer Enrollments:**
- First 5 payers shown by default
- Click "+X more payers" to see all
- Enrollment dates for each payer
- Status for each enrollment

## Understanding Your Limitations

### Why Can't I Edit?

As a Viewer, you have read-only access for several reasons:

1. **Data Integrity** - Prevents accidental changes
2. **Compliance** - Maintains audit trail
3. **Role Separation** - Clear responsibility boundaries
4. **Security** - Protects sensitive information

### What If I Need to Make Changes?

**Option 1: Request Manager Access**
- Contact your administrator
- Explain why you need edit access
- Admin can upgrade your role to Manager

**Option 2: Report to Manager**
- Find information that needs updating
- Report to a Manager or Admin
- They can make the changes

**Option 3: Document and Share**
- Take screenshots
- Note needed changes
- Share with appropriate person

4. Check spelling

**Solutions:**
1. Click directly on the text
2. Refresh page (F5)

### Issue: Statistics Don't Match

## Frequently Asked Questions

**Q: Why can't I export reports?**  
A: Export requires Manager or Admin role. Ask a Manager to export for you.

**Q: Can I print provider information?**  
A: Yes! Use browser print (Ctrl/Cmd + P) to print current view.

**Q: How do I request edit access?**  
A: Contact your administrator and explain why you need Manager role.

**Q: What does the red flag mean?**  
A: Provider is flagged for recredentialing (needs attention).

**Q: Can I see deleted providers?**  
A: No, deleted providers are removed from the system.

**Q: How often is data updated?**  
A: Real-time. Changes appear immediately.

**Q: Can I save searches?**  
A: Not currently, but this feature is planned.

**Q: What's the difference between Pending and Inactive?**  
A: Pending = credentialing in progress, Inactive = no longer active.
